# 宠物包设计

> 已实施。整理于 2026 年 10 月 10 日。

## 目标

- 宠物形象与数据来源（Claude Code / Codex）解耦：无论显示哪个来源，都使用同一只宠物，切换来源时宠物不变。
- 宠物以「宠物包」形式存在，新增形象只需要添加素材和描述文件，不改动固件或网页代码。
- 固件和网页只保留一套播放逻辑，统一使用雪碧图（图集）。
- 默认宠物为 Clawd。删除 Codex 宠物及其专属的触摸转头功能。

不在本次范围：从 Hub 下发宠物包、原创形象、宠物选择界面（见文末「后续」）。

## 宠物包

每只宠物一个目录：

```
assets/pets/
  index.json            宠物注册表：列出可用宠物和默认宠物
  clawd/
    sheet.webp          图集（无损 WebP，带透明通道）
    pet.json            描述文件
    pet.js              与 pet.json 内容相同，供网页（含 file:// 打开）以脚本形式加载
    source.json         素材来源、哈希、生成方式
```

`index.json`：

```json
{ "default": "clawd", "pets": ["clawd"] }
```

### 图集

最初设想是"每格同样大小、按顺序铺满"的雪碧图，但 Clawd 有 338 帧，每帧 374×233，铺满后整张图约 5984×5126。浏览器解码后约占 120MB 内存，也超过了 iOS 对单张图片的像素上限。因此改为图集：

- 完全相同的帧只存一份（338 帧中只有 111 帧不同）；
- 每帧只保留不透明的部分，按高度分行排进 2048 宽的图集；
- 每帧记录它在图集中的位置，以及在画布中的偏移。

Clawd 的图集为 2048×2342，文件约 8KB。

### pet.json

```json
{
  "id": "clawd",
  "name": "Clawd",
  "sheet": "sheet.webp",
  "size": { "width": 374, "height": 233 },
  "anchor": { "x": 14, "y": 0 },
  "frames": [[280, 1785, 210, 140, 94, 93], "..."],
  "animations": {
    "crab-walking": { "frames": [0, 0, 0, 0, 1, 2, "..."], "durations": [80, 90, "..."], "rest": 0,
                      "name": "小步走动", "alt": "Clawd 横向走路" }
  },
  "states": {
    "working": [{ "play": "crab-walking" }, { "play": "magnifier" }],
    "idle":    [{ "hold": "still", "ms": 4800, "name": "轻轻呼吸", "alt": "Clawd 安静陪伴" }, { "play": "cloud" }],
    "offline": [{ "hold": "still", "ms": 7000, "name": "等待连接", "alt": "Clawd 等待连接" }]
  },
  "eyes": { "still": [{ "x": 147, "y": 111, "w": 17, "h": 17, "color": "#d97757" }] }
}
```

字段说明：

| 字段 | 含义 |
| --- | --- |
| `size` | 帧画布的宽高。所有帧共用一个画布 |
| `anchor` | 画布左上角在宠物区域（固件 `companion` 面板，440×238）中的位置 |
| `frames` | 不同的帧：`[图集 x, 图集 y, 宽, 高, 画布 x, 画布 y]`。宽为 0 表示空白帧 |
| `animations.*.frames` | 按播放顺序列出的帧序号，可以重复引用同一帧 |
| `animations.*.durations` | 每帧时长（毫秒），与 `frames` 一一对应 |
| `animations.*.rest` | 静止时显示第几帧（减少动态、`hold`） |
| `states` | 状态对应的动作池，按顺序轮换，每个状态单独记录轮换位置。`play` 把动画完整播放一遍；`hold` 显示该动画的静止帧并停留 `ms` 毫秒 |
| `eyes` | 可选，仅网页使用：各动画静止帧上的眨眼遮罩位置（画布坐标） |

透明度只能是全透明或不透明，颜色不超过 255 种（固件以调色板存储）。

### 状态契约

宠物只认这 7 个状态：`working`、`waiting`、`done`、`idle`、`stopped`、`offline`、`error`。数据来源负责把会话数据归纳成这些状态，宠物不知道数据来自哪里。

`states` 中缺少某个状态时退回 `idle`，所以 `idle` 必须提供。

## 构建

### 生成宠物包：`scripts/build-pet-clawd.py`

1. 读取 `assets/clawd-official/` 中的原始素材，缩小到 480 宽（最近邻），**保留透明通道**，不合成背景。
2. 截取屏幕可见区域（480×323 中 x 20–460、y 90–323），计算所有帧的公共边界，得到画布尺寸和 `anchor`。
3. 去重、裁边、排进图集，写出 `sheet.webp`、`pet.json`、`pet.js` 和 `source.json`。
4. 校验：从编码后的图集还原每一帧，必须与源帧逐像素一致。

状态池、中文名称这类手写内容放在脚本的配置区，由脚本统一输出。

迁移时另做过一次对比：每一帧合成到背景色 `#141413` 后，与原 `assets/clawd-previews/*.gif` 的对应帧逐像素一致，帧时长和眨眼位置也一致。

新增宠物时，可以仿照这个脚本写生成脚本，也可以直接手工准备满足上述格式的 `sheet.webp` 和 `pet.json`，再在 `index.json` 中登记。

### 嵌入固件：`firmware/tools/embed_pets.py`

固件构建时由 CMake 调用，生成 `pets_assets.c`（结构定义见 `firmware/main/pet_pack.h`）：

- 所有颜色合成一张调色板（索引 0 为透明），帧存为 8 位索引。
- 每段动画的首帧完整保存；后续帧只保存与上一帧不同的矩形，矩形内容用 zlib 压缩；完全相同的矩形只存一份。
- 回放所有动画，逐帧校验还原结果。

Clawd 嵌入后约 25KB。原来的 8 段 GIF 加 Codex 宠物约 1.5MB。

## 固件

- `pet.c` 是通用播放器：根据状态从动作池取动作，把变化的矩形解压、经调色板展开到一张 RGB565A8 图像上，只让这个矩形区域重绘。
- 图像缓冲 374×233×3 ≈ 255KB，加上最大矩形大小的解压缓冲 ≈ 85KB，都在 PSRAM 中。屏幕本身是 RGB565，所以与原来的 ARGB8888 输出相同。
- 定时器按下一帧的到期时间休眠，不再每 40 毫秒轮询；停留帧（如离线时的 7 秒）期间不会唤醒。
- 接口为 `deskling_pet_state(const char *state)`，不再传数据来源；已删除 `deskling_pet_look()` 和触摸转头。点击宠物区域打开会话列表的功能不变。
- 暂停（打开浮层）时停止定时器，恢复后从当前帧剩余的时间继续。
- **行为变化**：`offline` 和 `error` 原来会把 GIF 冻结在当前帧，现在显示静止帧，与网页一致；`idle` 也与网页一致，在呼吸静止帧和云朵之间轮换。

## 网页

- 通过 `<script src="../assets/pets/clawd/pet.js">` 加载宠物包，`file://` 打开时同样可用。
- 播放器是一个以图集为背景的元素，每帧设置位置、尺寸和 `background-position`，按记录的时长逐帧切换，保持 `image-rendering: pixelated`。
- 呼吸、张望、思考等 CSS 动效和错误标记作为通用效果保留，所有宠物共用；眨眼遮罩读取 `pet.json` 的 `eyes`。
- 「下个动作」按钮、减少动态、页面隐藏或打开浮层时暂停等行为保持不变。

## 验证

- 生成脚本和嵌入脚本各自逐帧校验。
- `firmware/tools/preview/test_pet.c`：帧时长、增量帧与从关键帧回放的结果一致、动作池轮换、迟到追帧、停留帧期间休眠、暂停与恢复、未知状态退回 `idle`。
- UI 预览截图中，宠物的位置与原 GIF 首帧逐像素对齐，颜色差异不超过 RGB565 的精度。
- 网页：在 Chromium 中检查帧序列和时长、各情景、「下个动作」、自动轮换、减少动态，并确认没有脚本错误或资源加载失败。
- `hub` 测试通过。
- **待真机验证**：解码耗时和刷新表现。
